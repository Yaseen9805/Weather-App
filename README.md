# 🌦️ Weather App

A simple weather application built with **HTML, CSS, and JavaScript** that fetches real-time weather data using the OpenWeather API.

---

## 🚀 Features

* Search weather by city name
* Displays temperature, humidity, and conditions
* Dynamic weather icons (emoji-based)
* Error handling for invalid input
* Clean and responsive UI

---

## 🛠 Tech Stack

* HTML5
* CSS3
* JavaScript (Fetch API, Async/Await)

---

## ⚙️ How It Works

* Enter a city name and submit
* App fetches weather data from OpenWeather API
* Displays temperature, humidity, and description
* Shows relevant weather emoji

---

## 🔌 API Setup

This app uses the OpenWeather API.

Replace your API key in `index.js`:

```js id="cfwdnl"
const apikey = "YOUR_API_KEY";
```

Get your API key from: [https://openweathermap.org/api](https://openweathermap.org/api)

---

## ▶️ Run Locally

```bash id="l3p7ko"
git clone https://github.com/your-username/weather-app.git
cd weather-app
```

Open `index.html` in your browser.
